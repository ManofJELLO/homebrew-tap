# ManofJELLO/homebrew-tap

Homebrew tap for [AeroSpace_Jello](https://github.com/ManofJELLO/AeroSpace_Jello) —
a fork of [AeroSpace](https://github.com/nikitabobko/AeroSpace) that preserves the
tiled layout when a window enters and exits macOS native fullscreen.

## Install

```bash
brew install --cask ManofJELLO/tap/aerospace-jello
```

Conflicts with the upstream `aerospace` cask; uninstall that first.
