# ManofJELLO/homebrew-tap

Homebrew casks for ManofJELLO's macOS apps.

## AeroSpace_Jello

[AeroSpace_Jello](https://github.com/ManofJELLO/AeroSpace_Jello) is a fork of
[AeroSpace](https://github.com/nikitabobko/AeroSpace) that preserves the
tiled layout when a window enters and exits macOS native fullscreen.

```bash
brew install --cask ManofJELLO/tap/aerospace-jello
```

Conflicts with the upstream `aerospace` cask; uninstall that first.

## Fishsticks & Custard

[Fishsticks & Custard](https://github.com/ManofJELLO/fishsticks-and-custard) is a
voice assistant in the menu bar for Claude, Codex, Antigravity or OpenCode
(Apple silicon, macOS 13 or later).

```bash
brew install --cask ManofJELLO/tap/fishsticks-and-custard
fsc fetch-models
```
